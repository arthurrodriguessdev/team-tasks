
#  Stasker — Sistema de Gerenciamento de Equipes e Tarefas

## Descrição do Projeto

**Stasker** é um sistema web desenvolvido para o gerenciamento de equipes, projetos e tarefas. O objetivo do sistema é facilitar e centralizar a realização de projetos em pequenas empresas.

## Funcionalidades Principais do Sistema
- Dashboards com métricas relevantes
- Gestão de organizações, equipes e tarefas
- Sistema de autenticação e permissões
- Diferentes planos para os usuários
- Interface intuitiva
- Suporte interno aos usuários
- Mensagens e alertas de fácil entendimento

## Integrações Externas
O **Stasker** conta com algumas integrações com serviços externos, facilitando o processo de pagamentos e automações na comunicação.

### Brevo
- Envio de e-mails para verificação de contas
- Comunicação rápida com o usuário
- Integração via API REST

### Zoho
- Recebimento de e-mails dos usuários diretamente de dentro do **Stasker** solicitando suporte
- Integração via API REST
- Autenticação via OAuth 2.0

### Mercado Pago
- Processamento de pagamentos online
- Criação de checkout de pagamentos
- Webhooks (notificações) de eventos
- Integração via API REST
